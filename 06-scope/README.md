## Scope

- Scope বলতে বোঝায় কোন জায়গা থেকে একটি variable access করা যাবে। JavaScript-এ প্রধানত তিন ধরনের scope রয়েছে:

1. Global Scope
2. Function Scope
3. Block Scope

- What is the difference between function scope and block scope?

> Function scope: variable পুরো function-এর মধ্যে accessible।

> Block scope: variable শুধু নির্দিষ্ট { } block-এর মধ্যে accessible।
