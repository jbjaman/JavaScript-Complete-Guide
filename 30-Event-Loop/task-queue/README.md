- Callback Queue বা Task Queue কী?
- Callback Queue হলো এমন একটি Queue যেখানে নির্দিষ্ট Asynchronous Operation সম্পন্ন হওয়ার পর তার Callback Execution-এর জন্য অপেক্ষা করে।

- Q2. What is the Call Stack?
- The Call Stack is a Last-In, First-Out (LIFO) data structure used by the JavaScript engine to manage function execution contexts. When a function is called, its execution context is pushed onto the stack, and when it finishes, it is popped off.
