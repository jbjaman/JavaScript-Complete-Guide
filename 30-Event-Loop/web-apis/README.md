- Web APIs কী?
- Web APIs হলো Browser-এর দেওয়া কিছু সুবিধা, যা JavaScript Application-কে Browser-এর বিভিন্ন Feature ব্যবহার করতে দেয়।

- Web API ---- কাজ
  setTimeout ---- Timer
  setInterval ---- Repeated Timer
  fetch ---- HTTP Request
  DOM API ---- HTML Elements Manipulation
  addEventListener ---- User Events Handle
  localStorage ---- Browser Storage

- setTimeout() বা fetch() JavaScript Language-এর Core Syntax নয়। এগুলো Runtime Environment-এর API।
