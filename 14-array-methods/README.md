| Method    | কাজ                       | Return              |
| --------- | ------------------------- | ------------------- |
| map()     | প্রতিটি element transform | New Array           |
| filter()  | Condition অনুযায়ী select  | New Array           |
| find()    | প্রথম matching element    | Element / undefined |
| reduce()  | Single value তৈরি         | Single value        |
| forEach() | প্রতিটি element-এ কাজ     | undefined           |
| some()    | অন্তত একটি match          | Boolean             |
| every()   | সবগুলো match              | Boolean             |
