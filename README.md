### Variables

- Variable Scopes

> Variable scope determines the accessibility of variables in different parts of your code. JavaScript has three main types of scopes: a. Global scope b. Function scope c. Block scope. A local scope generally refers to either function scope or block scope, meaning the variable is only accessible within a limited region of the code.Finally, module scopes provide a way to encapsulate variables within a module, preventing them from polluting the global scope and allowing for better organization and reusability of code.
