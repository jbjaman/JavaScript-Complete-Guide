- Object হলো key-value pair-এর collection।
- প্রতিটা: (key → value) একটা property তৈরি করে। Object-এর Property-এর value যেকোনো type হতে পারে
- key: value
- real-world application-এর প্রায় সব entity-ই কোনো না কোনোভাবে object-এর মাধ্যমে represent করা যায়।
- basic syntax -> const objectName = {
  key: value,
  key: value,
  key: value };
- Property Access করতে দুইটা প্রধান উপায়: 1. Dot notation 2. Bracket notation

- Dot notation static property হলে সবচেয়ে readable
- কিন্তু dynamic property হলে bracket notation দরকার। এটা dynamic forms, filters, table columns, configuration-driven UI ইত্যাদিতে useful হতে পারে।
