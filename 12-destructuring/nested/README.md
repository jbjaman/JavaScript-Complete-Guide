- Function Parameter Destructuring useful. এটা readability বাড়ায়।

- Array Destructuring → position/index অনুযায়ী value নেয়

- Object Destructuring → property name অনুযায়ী value নেয়

- Alias → property-এর জন্য নতুন local variable name দেয়

- Nested Destructuring → nested structure-এর ভেতর থেকে সরাসরি value বের করে
