- Hoisting কী?

> JavaScript code execute করার আগে variable এবং function declaration-গুলোকে তাদের scope-এর শুরুতে process করে। এই behavior-কে Hoisting বলা হয়।

- Hoisting is JavaScript behavior where declarations are processed before code execution. Let and const are also hoisted, but they cannot be accessed before initialization because of the Temporal Dead Zone.
